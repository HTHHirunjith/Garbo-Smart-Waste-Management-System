# Garbo Smart Waste Management System

A Smart Waste Management System developed as part of the Second Year Software Development Project by a 5-member team.

## My Contributions

- Implemented JWT-based authentication and role-based authorization for 6 user roles in the Spring Boot backend, including protected REST APIs and council-level access control.
- Developed admin user-management functionality across the Spring Boot backend and Next.js web dashboard, including CRUD operations and validation.
- Contributed to the Flutter mobile application by developing login and password-recovery flows and integrating Firebase Cloud Messaging notifications.

## Technologies

- **Backend:** Java, Spring Boot, Spring Security, JWT
- **Web:** Next.js, React
- **Mobile:** Flutter
- **Database:** PostgreSQL
- **Notifications:** Firebase Cloud Messaging
- **Version Control:** Git, GitHub

The system consists of a Spring Boot backend, a Next.js web dashboard, and a Flutter mobile application, with supporting infrastructure for deployment.
